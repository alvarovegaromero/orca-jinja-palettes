# Third-party palettes

The palettes reuse the published color values of these themes, assigned to Jinja roles and
adjusted where needed to meet Orca's contrast checks. No theme files are copied. Each project's
name belongs to its authors; this plugin is not affiliated with them.

| Palette         | Based on                                                                             | License |
| --------------- | ------------------------------------------------------------------------------------ | ------- |
| One Dark        | [Atom One Dark](https://github.com/atom/atom/tree/master/packages/one-dark-syntax)   | MIT     |
| Dracula         | [Dracula](https://draculatheme.com) by Zeno Rocha                                    | MIT     |
| Monokai         | Monokai by Wimer Hazenberg                                                           | —       |
| Nord            | [Nord](https://www.nordtheme.com) by Arctic Ice Studio                               | MIT     |
| GitHub Light    | [GitHub VS Code theme](https://github.com/primer/github-vscode-theme)                | MIT     |
| Solarized Light | [Solarized](https://ethanschoonover.com/solarized/) by Ethan Schoonover              | MIT     |
